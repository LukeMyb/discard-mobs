# Spawn Blocker

ネザーにおける建築の自由度を確保し、景観を損なわずに安全な空間を構築するためのFabric用Modです。

## 開発の背景と目的

このModは、以下の2つの課題を解決するために作成されました。

* **明るさ依存の湧き潰しの限界**: ネザーに生息する多くのモブ（ゾンビピグリンやピグリンなど）は、オーバーワールドのモブとは異なり、明るさレベルに関わらずスポーンします。そのため、松明やグロウストーンによる従来の湧き潰しが機能せず、建築物の安全確保が極めて困難でした。
* **景観維持と建築のこだわり**: 従来のネザーにおける確実な湧き潰し方法は、下半ブロック（ハーフブロック）の設置やボタン、感圧版を敷き詰める手法が一般的です。しかし、これらは建築のデザインを大きく制限し、せっかく作り上げた景観を損ねてしまうという問題がありました。

「建築本来の美しさを保ったまま、ネザーに安全な拠点を築きたい」という想いから、このModは誕生しました。

---

## 機能概要

本Modは、モブがスポーンしようとした瞬間に、その足元のブロックを判定します。

* **人工ブロック上の湧きを遮断**: 石レンガや木材など、建築に使用される人工的なブロックの上ではモブのスポーンを無効化します。
* **自然環境の維持**: ネザーラック、ソウルサンドなどの自然生成されるブロックの上では、マインクラフト本来のスポーン条件（バイオームや距離の仕様）に従い、通常通りモブが湧きます。

これにより、拠点（駅や建築物）の内部のみをピンポイントで安全地帯にすることが可能です。
